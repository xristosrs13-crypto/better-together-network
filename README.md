# Better Together Network

Χάρτης συνεργατικών και αλληλέγγυων εγχειρημάτων της Αθήνας. Στατικό site (HTML/CSS/JS) που διαβάζει τα δεδομένα από ένα Google Sheet. Φιλοξενείται δωρεάν στο GitHub Pages.

## Πώς δουλεύει

- Τα δεδομένα ζουν σε ένα Google Sheet. Η ομάδα επεξεργάζεται μόνο το Sheet· το site ενημερώνεται μόνο του (με καθυστέρηση έως ~5 λεπτά λόγω cache της Google).
- Εμφανίζονται **μόνο** οι γραμμές με `consent = ΝΑΙ`. Οι γραμμές με `visibility = Private network` δεν εμφανίζονται ποτέ.
- `visibility = Limited`: φαίνονται μόνο όνομα, περιοχή, link και ένας διακεκομμένος κύκλος αντί για ακριβή θέση.
- Χάρτης: OpenStreetMap μέσω Leaflet.

## Σύνδεση με το Google Sheet

1. Στο Sheet: **Αρχείο → Κοινοποίηση → Δημοσίευση στον ιστό**.
2. Επιλέξτε το φύλλο «Εγχειρήματα» και μορφή **CSV (.csv)** → Δημοσίευση.
3. Αντιγράψτε το link και βάλτε το στο `config.js` στο `SHEET_CSV_URL`.

Προσοχή: όποιος έχει το link CSV βλέπει **όλες** τις γραμμές του φύλλου, και αυτές χωρίς συναίνεση. Γι' αυτό η λίστα έρευνας (επαφές, σημειώσεις, ευαίσθητες ομάδες) πρέπει να μένει σε **ξεχωριστό, μη δημοσιευμένο** φύλλο ή αρχείο. Στο δημοσιευμένο φύλλο μπαίνουν μόνο ομάδες που έχουν ήδη συναινέσει.

## Στήλες του φύλλου

| Στήλη | Περιεχόμενο |
|---|---|
| name | Όνομα |
| area | Περιοχή (γίνεται φίλτρο) |
| address | Διεύθυνση (μόνο για Public) |
| lat, lng | Συντεταγμένες (δεξί κλικ στο Google Maps → αντιγραφή) |
| intents | ΦΑΕ, ΑΓΟΡΑΣΕ, ΠΗΓΑΙΝΕ, ΒΟΗΘΗΣΕ (χωρισμένα με κόμμα) |
| legal_form | Νομική μορφή όπως τη δηλώνει η ομάδα |
| legal_verified | ΝΑΙ αν ελέγχθηκε στο Μητρώο ΚΑλΟ |
| traits | Χαρακτηριστικά, χωρισμένα με `;` |
| self_description | Πώς αυτοπροσδιορίζεται |
| description | Τι κάνει |
| how_it_works | Ιδιοκτησία, αποφάσεις, αμοιβές |
| hours | Ωράριο |
| website | Site ή social (π.χ. `https://…`) |
| hosts_events | ΝΑΙ / ΟΧΙ |
| how_to_support | Τρόποι στήριξης, χωρισμένοι με `;` |
| current_needs | Τρέχουσες ανάγκες, χωρισμένες με `;` |
| visibility | Public / Limited / Private network |
| consent | ΝΑΙ για να εμφανιστεί |
| last_confirmed | Ημερομηνία ΕΕΕΕ-ΜΜ-ΗΗ |

## Τοπική δοκιμή

```
python3 -m http.server 8000
```
και άνοιγμα του http://localhost:8000

## Πριν το δημόσιο άνοιγμα

Στο `index.html` αφαιρέστε τη γραμμή `<meta name="robots" content="noindex">` ώστε να εμφανίζεται το site στις μηχανές αναζήτησης.
